Exercice 3.1 (questions)
Quelle est la retenue maximale qu'on peut avoir en additionnant des octets :
Avec cette retenue + 255 + 255, quel est le nombre à mettre en bas :
-------------------------------------------------------------------
En base 10, la plus grande retenue possible lors de l'addition de deux chiffres est 1.
En utilisant des octets (représentant des chiffres dans la base 256), la valeur maximale d'un octet est 255. Lorsque l'on ajoute deux octets maximum (255 + 255), cela donne :
  255
+ 255
-----
  510
Dans ce cas, le résultat de 255 + 255 est 510. La valeur maximale que peut avoir une retenue dans cette addition est donc 1 (retenue de 1).
Si l'on a déjà une retenue de 1 lors de l'addition de 255 + 255, cela donne :
    1    (retenue)
  255
+ 255
-----
  511
Ainsi, la plus grande retenue possible lors de l'addition de deux octets (255 + 255 avec une retenue de 1) est 1.
